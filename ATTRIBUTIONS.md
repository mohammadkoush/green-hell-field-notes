# Icon sources

Silhouettes from [PhyloPic](https://www.phylopic.org/), accepted only when the
licence is public domain / CC0, or CC-BY with the author named below.
NonCommercial and ShareAlike images are refused: this mod is assumed to be
published, and a gap in the icon set is recoverable where a licence violation
is not. Originals are kept in `icons-src/sourced/`.
